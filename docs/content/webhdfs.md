# WebHDFS

[WebHDFS](https://hadoop.apache.org/docs/r1.0.4/webhdfs.html) is the HTTP
REST API of the [Apache Hadoop](https://hadoop.apache.org/) Distributed
Filesystem (HDFS). It lets rclone talk directly to a namenode (or an
HttpFS gateway) over plain HTTP(S), so no native Hadoop client libraries
are required.

Paths are specified as `remote:` or `remote:path/to/dir`.

## Configuration

Here is an example of how to make a remote called `remote`. First run:

```console
rclone config
```

This will guide you through an interactive setup process:

```text

```

This remote is called `remote` and can now be used like this

See all the top level directories

```console
rclone lsd remote:
```

List the contents of a directory

```console
rclone ls remote:directory
```

Sync the remote `directory` to `/home/local/directory`, deleting any excess files.

```console
rclone sync --interactive remote:directory /home/local/directory
```

### Modification times

Time accurate to 1 millisecond is stored, using the `SETTIMES` WebHDFS operation.

### Checksum

No checksums are implemented.

### Restricted filename characters

In addition to the [default restricted characters set](/overview/#restricted-characters)
the following characters are also replaced:

| Character | Value | Replacement |
| --------- |:-----:|:-----------:|
| :         | 0x3A  | ：           |

Invalid UTF-8 bytes will also be [replaced](/overview/#invalid-utf8).

### Standard options

Here are the Standard options specific to webhdfs (Hadoop distributed file system over HTTP (WebHDFS)).

#### --webhdfs-url

URL of the WebHDFS namenode (or HttpFS server).

E.g. "http://namenode:9870".

Properties:

- Config:      url
- Env Var:     RCLONE_WEBHDFS_URL
- Type:        string
- Required:    true

#### --webhdfs-username

Hadoop user name.

Set this when security is off - it is sent as the "user.name" parameter.

Properties:

- Config:      username
- Env Var:     RCLONE_WEBHDFS_USERNAME
- Type:        string
- Required:    false
- Examples:
  - "root"
    - Connect to WebHDFS as root.

#### --webhdfs-password

Password.

Set this together with username to use HTTP Basic Authentication.

**NB** Input to this must be obscured - see [rclone obscure](/commands/rclone_obscure/).

Properties:

- Config:      password
- Env Var:     RCLONE_WEBHDFS_PASSWORD
- Type:        string
- Required:    false

### Advanced options

Here are the Advanced options specific to webhdfs (Hadoop distributed file system over HTTP (WebHDFS)).

#### --webhdfs-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

Properties:

- Config:      encoding
- Env Var:     RCLONE_WEBHDFS_ENCODING
- Type:        Encoding
- Default:     Slash,Colon,Del,Ctl,InvalidUtf8,Dot

#### --webhdfs-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_WEBHDFS_DESCRIPTION
- Type:        string
- Required:    false
